1. **Mission debrief:** After each mission, users should see their performance, completed objectives, mistakes and results.

2. **AI companion drone:** The drone should act as the main AI guide, helping users understand missions, objectives and tasks. The astronaut will be a visual character, not the guide.

3. **Simple mission transitions:** Smooth transitions between mission stages using lightweight UI animations. No need for additional 3D scenes or complicated graphics.

4. **Earth clock comparison:** Show the current Earth/UTC time alongside the user's local time, with both clocks updating live.

5. **User profile and mission history:** Users should be able to see their progress, completed missions and previous results.

6. **Achievements and leaderboard:** Add achievements for mission completion and milestones. A leaderboard can be considered later.

7. **3D asset integration:** Use our existing astronaut, drone, rover, lunar module and other 3D assets where they add value, without making the interface overcrowded.
